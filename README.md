# 🚀 AI Studio - متجر اشتراكات الذكاء الاصطناعي

موقع متكامل وعصري لبيع اشتراكات الذكاء الاصطناعي (Gemini Pro, ChatGPT Plus, CapCut Pro) مبني بأحدث التقنيات **Next.js (App Router)** و **Tailwind CSS**، وجاهز للرفع مباشرة بنقرة واحدة على منصة **Vercel**.

---

## 🌟 مميزات المشروع

- **تصميم استثنائي (Dark & Neon Mode)**: واجهة مستخدم مبهرة بإضاءات نيون زرقاء وبنفسجية وتأثيرات زجاجية (Glassmorphic) وتجاوب كامل مع كافة الشاشات (Mobile & Desktop).
- **تحويل مباشر للواتساب**: أزرار شراء ديناميكية تقوم بتحويل المستخدم تلقائياً إلى تطبيق WhatsApp مع رسالة مجهزة تتضمن اسم المنتج والسعر ودورة الاشتراك.
- **تكامل شبكات التواصل**: زِر خاص بالتوجيه لصفحة الفيسبوك الرسمية (`NEXT_PUBLIC_FACEBOOK_URL`) وزر واتساب عائم للتواصل السريع.
- **لوحة تحكم إدارية محمية (`/admin`)**:
  - تسجيل دخول آمن باستخدام بروتوكول الكوكيز المحمية (HTTP-Only Secure Cookies) والتشفير بـ HMAC-SHA256.
  - إمكانية إضافة منتج جديد (الاسم، السعر، المميزات، الشارة، رابط الصورة، نص الواتساب).
  - إمكانية تعديل المنتجات الحالية أو حذفها بسهولة مع حفظ فوري للبيانات.
- **توافق 100% مع Vercel**: نظام تخزين ذكي يعمل بملف JSON محلي في بيئة التطوير المحلية ويتحول تلقائياً لنظام ذاكرة سيرفرلس (Serverless In-Memory) عند النشر بدون الحاجة لقواعد بيانات خارجية معقدة.

## ⚙️ متغيرات البيئة (Environment Variables)

قم بإنشاء ملف `.env.local` في جذر المشروع وأضف المتغيرات التالية:

```env
# رقم الواتساب الذي سيتم تحويل طلبات الشراء إليه (شاملاً كود الدولة بدون +)
NEXT_PUBLIC_WHATSAPP_NUMBER=201000000000

# رابط صفحة الفيسبوك الخاصة بالموقع
NEXT_PUBLIC_FACEBOOK_URL=https://facebook.com/aistudio.official

# بيانات دخول لوحة تحكم الأدمن
ADMIN_USERNAME=admin
ADMIN_PASSWORD=aistudio2026

# المفتاح السري لتشفير الجلسات (قم بتغييره في بيئة الإنتاج)
JWT_SECRET=super-secret-key-aistudio-2026
```

## 🛠️ خطوات التشغيل والتثبيت محلياً (Local Development)

### 1. تثبيت الاعتماديات
افتح المجلد في موجه الأوامر (Terminal) ونفذ:

```bash
npm install
```

### 2. تشغيل سيرفر التطوير
شغّل الأمر التالي لبدء المشروع محلياً:

```bash
npm run dev
```

افتح المتصفح على الرابط: `http://localhost:3000`

- **كلمة المرور الافتراضية**: `aistudio2026`
*(يمكنك تعديل هذه البيانات في ملف `.env.local` في أي وقت)*

## ☁️ خطوات النشر المباشر على منصة Vercel (Vercel Deployment Guide)

1. قم برفع المشروع على حسابك في **GitHub** أو **GitLab**.
2. سجل الدخول إلى لوحة **Vercel** واضغط على **Add New Project**.
3. اختر المستودع الخاص بمشروع **AI Studio**.
4. في قسم **Environment Variables** في Vercel، أضف المتغيرات التالية:
   - `NEXT_PUBLIC_WHATSAPP_NUMBER`
   - `NEXT_PUBLIC_FACEBOOK_URL`
   - `ADMIN_USERNAME`
   - `ADMIN_PASSWORD`
   - `JWT_SECRET`
5. اضغط على **Deploy**. سيقوم Vercel ببناء المشروع وتوفير رابط مجاني ومباشر يعمل بكفاءة وسرعة فائقة!
